# Source origin

This package contains an independently authored MIT-licensed DotNative
implementation using DotNative native channels and platform APIs.

Android uses external Apache-2.0 dependencies: AndroidX DataStore,
Google Tink Android and Kotlin coroutines. Dependencies are resolved by Gradle;
their source code is not copied into this repository.

- DataStore: https://developer.android.com/jetpack/androidx/releases/datastore
- Tink: https://github.com/tink-crypto/tink-java
- Coroutines: https://github.com/Kotlin/kotlinx.coroutines
- Apple Keychain: https://developer.apple.com/documentation/security/keychain-services
